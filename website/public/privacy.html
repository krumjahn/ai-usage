Activity collection

The app stores foreground app names and bundle IDs, recognized AI domains, time intervals and classification provenance in a local SQLite database. It excludes idle and sleep gaps. Browser identification is optional and uses macOS Automation permission.

It never stores prompts, source code, window titles, page contents, full URLs or unrecognized website domains. Generic terminal use is not attributed to an AI agent. The app does not upload activity, connect provider accounts, or measure tokens.

Your controls

Settings lets you pause recording, turn website identification on or off, export local records as JSON, and delete history after confirmation. History lives at ~/Library/Application Support/com.rumjahn.attentionledger/activity.sqlite. Deletion clears the app database; copies in your exports or device backups are managed separately.

Optional product feedback

When a feedback service is connected, the app can ask three optional questions: why you downloaded it, what you use AI for, and what you want next. Skip sends nothing. Only pressing Send feedback submits your choices, optional text (up to 500 characters), app version, form schema version and a random submission ID. The service adds a receipt timestamp. There is no persistent installation ID, account or email field.

Responses are privately stored in Cloudflare D1 and deleted after 90 days by a daily retention job. Cloudflare processes connection metadata such as your IP address; it is used transiently for rate limiting and is not saved in the response table. Do not include personal or confidential details. Responses are used by the project maintainer to prioritize improvements.

The current preview has no live feedback endpoint. Automatic onboarding is disabled until it is connected. You can suggest ideas on GitHub instead, where posts are public.

This website

This static site uses no analytics scripts, advertising, cookies or third-party fonts. Its hosting provider processes normal connection metadata to serve it. Video plays only when you start it. Following GitHub links uses GitHub’s own service and privacy practices.

Questions and source

Read the source code or open a GitHub issue. Don’t attach activity exports, credentials or personal data to public issues.
