# AI Usage media

- [14-second product demo](ai-usage-demo.mp4): H.264 MP4, 1920×1080, 30fps, silent. A staged macOS desktop shows the pointer clicking the menu-bar time, opening the native dashboard, then clicking away.
- [Native app screenshots](../images): dashboard in light/dark mode, seven-day view, Settings, and the optional feedback form.

All usage numbers are illustrative. Images come from the real SwiftUI views rendered with synthetic records in a temporary database; no personal activity history is included. The optional feedback form is inactive in the current preview until its service is connected.

Screenshot generator: `scripts/screenshots.sh`. Editable video source: `promo/`. These assets can be shared independently of a website. Product names and icons belong to their respective owners.
